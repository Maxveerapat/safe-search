Add Search Safety Flagger to Chrome

Labels every Google result with a safety tag on your phone, in normal Chrome. Setup takes about 2 minutes and is done once.

Show the code

Save it as a bookmark

  1. Tap Copy code above.
  2. In Chrome, tap ⋮ then ☆ to bookmark this page. Chrome shows “Bookmarked”. Tap Edit.
  3. Change the name to ssf.
  4. Clear the URL box, long-press it and Paste. It should start with javascript:. Tap back to save.
Easier on a computer: with Chrome sync on, do the same steps in Chrome on your computer. The bookmark appears on your phone automatically.

Use it

  1. Search Google in Chrome as usual.
  2. Tap the address bar, type ssf, and tap the suggestion with the ☆ star.
  3. Labels appear on every result. Use ⚙ Filter to hide categories, tap a label for its dated history, and tap ✕ to turn it off.
Tapping the bookmark from Chrome's Bookmarks screen does not run it on Android. Always type ssf in the address bar.
